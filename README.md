# 🍽️ Restaurants API

A scalable RESTful API for managing restaurants and their dishes, built using **ASP.NET Core**, **Clean Architecture**, and **CQRS** principles.

This project demonstrates a production-style backend architecture with clear separation of concerns and maintainable design.

---

##  Features

- Manage Restaurants
- Manage Dishes per restaurant
- Clean Architecture structure
- CQRS pattern using MediatR
- Repository pattern
- Global error handling
- Logging support
- Entity Framework Core integration
- RESTful API design
- Swagger API documentation

---

## 🏗️ Architecture

The project follows **Clean Architecture**:


### Layer Responsibilities

- **Domain** → Business entities and rules
- **Application** → CQRS commands & queries
- **Infrastructure** → Database and external integrations
- **API** → Controllers and middleware
